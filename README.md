# 보안·개인정보 규제 대응 보드

[대시보드](https://jhn88100-afk.github.io/security-briefing/)

## 동기화

상단 **기관 자료 동기화** → GitHub Actions **Run workflow** → 기간 선택 후 실행. 완료 후 대시보드에서 **결과 새로고침**.

- GitHub 저장소 쓰기 권한이 있는 계정으로 실행합니다. 공개 화면에 인증키를 저장하지 않습니다.
- 공식 게시판 첫 페이지의 제목·게시일·링크를 수집하고 URL 기준 중복을 제거합니다. 전체 이력·전체 기관 수집을 보장하지 않습니다.
- 자동 수집 항목은 **원문 검토 대기**입니다. 본문·첨부파일·시행일·의무 여부는 검토 후 확정해야 합니다.
- 차단·구조 변경·파싱 실패는 확인 필요로 표시합니다. 수집 성공을 법령 검증 완료로 간주하지 않습니다.
- 과기정통부·금감원·레그테크 등 아직 어댑터가 없는 기관은 수동 확인이 필요합니다. dot 알림 동기화와는 별개입니다.
- 티켓 상태·메모는 해당 브라우저에만 저장됩니다.

## 구성

`data.js`: 기존 검토 자료와 수집 후보 / `sources.json`: 연결 게시판 / `scripts/collect.py`: 수집기 / `.github/workflows/sync.yml`: 수동 수집·배포 작업.

개인정보·내부 증적은 입력하지 마세요.
